# quantum-operations-frontend-DWA-2026

Фронтенд приложения для работы с квантовыми вентилями (Quantum Gates) на React + TypeScript + Vite.

## Технологический стек

- **Frontend:** React 18, TypeScript, Vite
- **Стилизация:** CSS3, React-Bootstrap, Bootstrap 5
- **Маршрутизация:** React Router DOM v6
- **Иконки:** Emoji

## Страницы приложения

### 1. Плитка гейтов (`/`)
Сетка квантовых вентилей с фильтрацией по названию и углам X/Y.
- Поле поиска по названию
- Два диапазона слайдеров для угла X (0–180°)
- Два диапазона слайдеров для угла Y (0–180°)
- Кнопка "Применить"
- Карточки вентилей с изображением, названием, описанием, углами

### 2. Лента вентилей (`/feed`)
Вертикальная лента квантовых вентилей, как в TikTok.
- Видео или изображение вентиля на весь экран
- Параметры угла X и Y
- Количество лайков
- Описание с кнопкой "Ещё/Меньше"
- Кнопка "Следующий гейт" для перехода к следующему вентилю

### 3. Добавление вентиля (`/add`)
Форма добавления нового квантового вентиля.
- Шаг 1: Название, фото, видео, кнопка "Далее"
- Шаг 2: Название, фото, видео, описание, угол X, угол Y, кнопка "Опубликовать"
- Поля фото и видео расположены друг под другом
- Нет лишнего текста

### 4. Вход (`/login`)
Страница аутентификации и регистрации.
- Поля: логин, пароль
- Кнопки: "Войти", "Зарегистрироваться"

## Навигационная панель

Нижняя таб-панель с 4 пунктами:
- **Плитка** — переход на страницу плитки гейтов
- **Лента** — переход на страницу ленты гейтов
- **Добавить** — переход на страницу добавления вентиля
- **Вход** — переход на страницу входа

## Запуск приложения

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр сборки
npm run preview
```

Приложение будет доступно по адресу: http://localhost:3000
