# quantum-operations-frontend-DWA-2026

Фронтенд приложения для работы с квантовыми вентилями (Quantum Gates) на React + Vite.

## Технологический стек

- **Frontend:** React 18, Vite
- **Стилизация:** CSS3, React-Bootstrap, Bootstrap 5
- **Маршрутизация:** React Router DOM v6
- **Хранение данных:** мок-данные + `localStorage`

## Страницы приложения

### 1. Плитка гейтов (`/`)
Сетка квантовых вентилей с фильтрацией по названию и углам X/Y.

- Поле поиска по названию
- Диапазоны углов X и Y (0–180°)
- Карточки с изображением, названием, автором, описанием и углами
- Клик по карточке открывает этот гейт в ленте
- Кнопка «Удалить» на каждой карточке:
  - **красная** — если текущий пользователь является автором карточки;
  - **бирюзовая** — для гостя и для любого другого пользователя.
- Гость и не-автор при нажатии получают уведомление об отсутствии прав.

### 2. Лента вентилей (`/feed`, `/feed/:id`)
Вертикальная лента квантовых вентилей, как в TikTok.

- Видео гейта на весь экран; при переключении гейта загружается именно его видео
- Параметры угла X и Y
- Одна кнопка лайка: сердце и счётчик на одной кнопке
  - нажатие закрашивает сердце и увеличивает счётчик на 1;
  - повторное нажатие убирает лайк и уменьшает счётчик на 1;
  - гость получает уведомление с предложением войти.
- Описание с кнопкой «Ещё/Меньше»
- Кнопка «Следующий гейт»

### 3. Добавление вентиля (`/add`)
Доступно только авторизованным пользователям.

- Шаг 1: название, фото, видео → кнопка «Далее»
- Шаг 2: описание, угол X, угол Y → кнопка «Опубликовать»
- После публикации гейт сразу появляется в плитке и ленте
- Гость видит сообщение о необходимости входа, поля и кнопки недоступны

### 4. Вход и регистрация (`/login`, `/register`)
- Поля: логин, email (при регистрации), пароль
- Пароль скрыт, есть кнопка «Показать/Скрыть»
- Вход и выход выполняются через Axios (`POST /api/users/login`, `/api/users/logout`), сессия хранится в cookie `session_id`
- Если веб-сервис недоступен, включается демо-режим с локальными пользователями (для показа интерфейса без бэкенда)
- Повторная регистрация с существующим логином или email блокируется
- Зарегистрированные пользователи сохраняются в базе веб-сервиса

Демо-аккаунты (офлайн-режим):

| Логин | Пароль |
|-------|--------|
| `admin` | `admin123` |
| `user1` | `user123` |

### 5. Подробнее об услуге (`/gates/:id`)
- Полная карточка: фото, автор, описание, углы X/Y, количество лайков
- Блок «Характеристики услуги» — произвольный список пар «название — значение»
  из таблиц `attributes` и `gate_attributes` (связь m-m)

## ЛР-6: Redux Toolkit, Axios и работа с веб-сервисом

- **Состояние:** Redux Toolkit (`auth`, `gates`, `filters`, `ui`), Redux DevTools.
- **Запросы:** Axios + клиент `src/api/generated/quantumGatesApi.js`, сгенерированный по Swagger;
  вызовы обёрнуты в `createAsyncThunk` (`fetchGates`, `createGate`, `likeGateById`, `deleteGateById`).
- **Фильтры:** поиск, углы X/Y и сортировка хранятся в `filtersSlice` и передаются в `GET /api/gates`.
  При выходе фильтры сбрасываются.
- **CORS:** в dev-режиме запросы идут через прокси Vite: `/api` → FastAPI, `/s3` → MinIO.
- **Mock-данные:** если бэкенд недоступен, гость видит локальную коллекцию mock-объектов;
  авторизованный пользователь работает только с веб-сервисом.
- **Загрузка:** во время AJAX-запроса показывается блокирующая анимация.
- **Атрибуты:** редактор характеристик при добавлении услуги и отдельная страница «Подробнее об услуге».

Запуск вместе с бэкендом:

```bash
# в папке quantum-operations-backend-DWA-2026
docker compose up -d postgres redis
alembic upgrade head
uvicorn main:app --reload

# в папке фронтенда
npm install
npm run dev
```

## Навигационная панель

Нижняя таб-панель всегда содержит три пункта:

- **Плитка** — страница плитки гейтов
- **Лента** — страница ленты гейтов
- **Добавить** — страница добавления вентиля

Кнопка «Вход» (а для авторизованного пользователя — имя и «Выйти») находится в шапке приложения справа.

## Права доступа

| Действие | Гость | Авторизованный пользователь |
|----------|-------|------------------------------|
| Просмотр плитки и ленты | да | да |
| Открытие карточки в ленте | да | да |
| Просмотр количества лайков | да | да |
| Постановка лайка | нет | да |
| Добавление гейта | нет | да |
| Удаление гейта | нет | только своих карточек |

## Запуск приложения

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр сборки
npm run preview
```

Приложение будет доступно по адресу: http://localhost:3000

```
src/

│   ├── mappers.js          # Приведение ответов API и mock к модели
│   ├── media.js            # Адреса медиа через прокси (в т.ч. /s3)
│   └── generated/
│       └── quantumGatesApi.js  # Клиент, сгенерированный по Swagger
├── components/
│   ├── GateCard.jsx        # Карточка гейта
│   ├── LoadingOverlay.jsx  # Блокирующая анимация и уведомления
│   └── Navbar.jsx          # Нижняя таб-панель
├── hooks/
│   ├── useAuth.js          # Устаревший хук (совместимость)
│   └── useGates.js         # Устаревший хук (совместимость)
├── pages/
│   ├── GridPage.jsx        # Плитка и фильтрация
│   ├── FeedPage.jsx        # Лента, видео и лайки
│   ├── GateDetailsPage.jsx # Подробнее об услуге + атрибуты
│   ├── AddPage.jsx         # Двухшаговая публикация
│   └── LoginPage.jsx       # Вход и регистрация
├── store/
│   ├── index.js            # configureStore
│   ├── gatesStore.js       # Mock-коллекция в localStorage
│   ├── slices/             # auth, gates, filters, ui
```
