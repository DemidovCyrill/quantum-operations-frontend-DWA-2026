# Полная инструкция по запуску проекта

Проект состоит из двух репозиториев:

| Часть | Папка | Стек |
|---|---|---|
| Фронтенд | `quantum-operations-frontend-DWA-2026` | React 18, Vite 5, Redux Toolkit, Axios, React-Bootstrap |
| Бэкенд | `quantum-operations-backend-DWA-2026` | Python 3.13, FastAPI, SQLAlchemy 2 (async), PostgreSQL, Redis, MinIO |

Ветки ЛР-6:

- фронтенд — `lab6-redux-toolkit`;
- бэкенд — `lab6-attributes`.

---

## 1. Что должно быть установлено

- **Node.js 20+** и **npm 10+**;
- **Python 3.13**;
- **Docker Desktop** (PostgreSQL и MinIO);

- **Memurai** или Redis на порту `6380` (на этом компьютере Memurai уже установлен);
- браузер Chrome/Edge;
- расширение **Redux DevTools** для браузера;
- по желанию: Postman/Insomnia, Adminer/pgAdmin.

Порты по умолчанию:

| Порт | Что |
|---|---|
| 3000 | фронтенд (Vite) |
| 8000 | бэкенд (FastAPI) |
| 5433 | PostgreSQL |
| 6380 | Redis |
| 9000 / 9001 | MinIO API / MinIO Console |

## 2. Запуск бэкенда

Откройте PowerShell в папке `quantum-operations-backend-DWA-2026`.

### 2.1. Виртуальное окружение

В проекте уже есть окружение `quantum_operations`. Активируйте его:

```powershell
.\quantum_operations\Scripts\Activate.ps1
```

Если PowerShell блокирует запуск скриптов:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Если окружения нет, создайте новое:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2.2. Зависимости

```powershell
pip install -r requirements.txt
```

### 2.3. Проверьте `.env`

Файл `.env` в корне бэкенда:

```dotenv
DB_HOST=127.0.0.1
DB_PORT=5433
DB_USER=myuser
DB_PASSWORD=mypassword
DB_NAME=quantum_db

MINIO_URL=http://localhost:9000/quantum-operations
USE_MINIO=false
CURRENT_USER_ID=1
```

`USE_MINIO=false` — файлы хранятся локально в `static/uploads` (значение по умолчанию).
Для скриншота с S3 поставьте `USE_MINIO=true` (см. раздел 5).

### 2.4. Запустите PostgreSQL, Redis и MinIO

PostgreSQL из готового образа:

```powershell
docker compose up -d postgres
```

Если контейнер уже создан ранее, достаточно:

```powershell
docker start gates_postgres
```

**Redis.** На этом компьютере уже установлен и запущен **Memurai** — Redis-совместимый
сервер на порту `6380`, который использует бэкенд. Отдельный контейнер Redis не нужен:

```powershell
Get-Service Memurai
```

Если Memurai не запущен:

```powershell
Start-Service Memurai
```

Вариант с Docker (только если образ `redis:7` уже есть локально):

```powershell
docker compose --profile docker-redis up -d redis
```

MinIO нужен только для варианта с S3:

```powershell
docker compose up -d minio
```

Проверка контейнеров:

```powershell
docker ps
```

Должны быть `gates_postgres` (5433), при необходимости `minio_storage` (9000/9001),
а Redis — служба `Memurai` на порту `6380`.

### 2.5. Примените миграции

```powershell
alembic upgrade head
```

Миграция `3f1a9c7d2b10` создаёт таблицы `attributes` и `gate_attributes` и заполняет
характеристики для уже существующих гейтов.

Если база пустая и миграции применяются впервые — выполнятся все миграции по порядку.

### 2.6. Запустите сервер

```powershell
uvicorn main:app --reload
```

Проверка:

- Swagger: http://127.0.0.1:8000/docs
- Список услуг: http://127.0.0.1:8000/api/gates

## 3. Запуск фронтенда

Откройте второй терминал в папке `quantum-operations-frontend-DWA-2026`.

```powershell
npm install
npm run dev
```

Приложение: http://localhost:3000

Vite проксирует запросы:

- `/api` → `http://127.0.0.1:8000`;
- `/s3` → `http://127.0.0.1:9000` (MinIO);
- `/static/uploads` → `http://127.0.0.1:8000`.

Поэтому браузер обращается только к `localhost:3000`, и CORS не требуется.

### Если бэкенд не запущен

Гость увидит демонстрационные данные (mock) и бейдж «демо-данные (mock)».
Это специально предусмотрено для скриншотов 1–2.
Авторизованный пользователь при недоступном бэкенде получит ошибку — это нормально.

## 4. Первый вход

1. Откройте http://localhost:3000.
2. Нажмите **«Вход»** → **«Зарегистрироваться»**.
3. Введите логин (от 3 символов), email и пароль (от 5 символов).
4. После регистрации произойдёт автоматический вход.

Демо-аккаунты только для офлайн-режима (без бэкенда):

| Логин | Пароль |
|---|---|
| `admin` | `admin123` |
| `user1` | `user123` |

С запущенным бэкендом пользователи берутся из PostgreSQL; при необходимости
создайте их через регистрацию или SQL.

---

## 5. Вариант с MinIO (для скриншота 16)

1. Запустите MinIO:

```powershell
docker compose up -d minio
```

2. В `.env` бэкенда установите:

```dotenv
USE_MINIO=true
```

3. Перезапустите `uvicorn`.

4. MinIO Console: http://127.0.0.1:9001
   Логин: `minioadmin`, пароль: `minioadmin`.

5. Загрузите услугу с фото/видео. В Network будет URL вида
   `/s3/quantum-operations/<uuid>.<ext>`, а объект появится в бакете
   `quantum-operations`.

Политика публичного чтения бакета создаётся автоматически при первой загрузке.

## 6. Проверка, что всё работает

- [ ] `http://127.0.0.1:8000/docs` открывается, видны методы `/api/gates`, `/api/attributes`, `/api/users`.
- [ ] `http://localhost:3000/` показывает бейдж «данные веб-сервиса» (при запущенном бэкенде).
- [ ] Вход/регистрация работают, в шапке появляется имя пользователя.
- [ ] После публикации открывается `/gates/{id}` с блоком «Характеристики услуги».
- [ ] У своих карточек кнопка «Удалить» красная, у чужих и у гостя — бирюзовая.
- [ ] В ленте при переключении гейта меняется видео.
- [ ] В Redux DevTools видны `auth`, `gates`, `filters`, `ui`.

## 7. Частые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| `ModuleNotFoundError: redis` / `asyncpg` | не активировано окружение | активировать `quantum_operations` и `pip install -r requirements.txt` |
| `sqlalchemy.exc.OperationalError` | PostgreSQL не запущен или неверный порт | `docker compose up -d postgres`, проверить `DB_PORT=5433` |
| `redis.exceptions.ConnectionError` | Redis/Memurai не запущен | `Start-Service Memurai` (порт 6380) или `docker compose --profile docker-redis up -d redis` |
| `failed to resolve reference ... redis:7` | зеркало Docker недоступно | не тянуть Redis: использовать Memurai на 6380; Postgres уже есть в образе |
| `alembic: connection refused` | база не готова | подождать 5–10 секунд после `docker compose up`, повторить |
| В браузере 500 на `/api/...` | бэкенд не запущен | запустить `uvicorn`; для гостя включится mock |
| 401 при лайке/удалении | нет cookie сессии | войти заново, проверить `withCredentials` в Axios |
| `CORS` в консоли | запрос идёт на `:8000` напрямую | использовать относительный `/api` через прокси Vite |
| Порт 3000 занят | запущен другой Vite | закрыть процесс или изменить порт в `vite.config.ts` |
| Фото 404 | не проксируется `/static/uploads` | проверить `vite.config.ts`, путь `image_url` |
| MinIO 403 | закрытая политика бакета | перезапустить бэкенд: политика выставляется при загрузке |
| `pip install -r` падает | старая кодировка файла | файл `requirements.txt` уже переведён в UTF-8 |

## 8. Остановка

```powershell
# остановить uvicorn и vite — Ctrl+C в соответствующих терминалах
docker compose stop
```

Полностью удалить контейнеры (данные в volume сохранятся):

```powershell
docker compose down
```

Удалить и данные:

```powershell
docker compose down -v
```
